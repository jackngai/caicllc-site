Agents & Sub-Agents

Level 2, intermediate. Your first weeks with Claude Code or Codex: how an agent uses tools and files, when to split work across sub-agents, and how to keep it on the rails.

Updated October 4, 2026

This guide is for builders who have moved past simple chat interfaces and want to use terminal-based agents to edit code and run local workflows. You will learn to configure agents with custom tools, manage long-term project context, and delegate complex tasks to specialized sub-agents. By the end, you will be able to build a reliable local environment where AI helps manage your development lifecycle autonomously.

Who this is for: You are trying Claude Code or Codex for the first time and want your agent to use tools, edit files, and delegate to sub-agents well.
