Agents & Sub-Agents

Level 2, intermediate. Your first weeks with Claude Code or Codex: how an agent uses tools and files, when to split work across sub-agents, and how to keep it on the rails.

Updated July 12, 2026

This guide is for people trying a coding agent such as Codex or Claude Code for the first time after getting comfortable with ordinary AI chat. You will learn how agents use tools, files, commands, context, sub-agents, and connectors, then practice giving them work in a way that stays understandable and reviewable.

Who this is for: You are trying Claude Code or Codex for the first time and want your agent to use tools, edit files, and delegate to sub-agents well.
