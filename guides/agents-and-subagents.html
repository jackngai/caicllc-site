Agents & Sub-Agents

Deep dives on designing agents, delegating to sub-agents, and keeping multi-agent systems on the rails.

Updated June 25, 2026

This guide is for people who want agents to do useful work without turning their workflow into a fragile science project. It focuses on the practical layer around the model: skills, loops, sub-agents, memory, tools, verification, and model routing. The goal is to help individuals and small businesses choose agent patterns that are reliable enough to run, inspect, and improve.

In this guide

Designing Agent Loops That Stop for the Right Reason

Agent loops work when recurring tasks are framed around explicit triggers, bounded tool access, verifiable stop conditions, durable memory, and a budget-aware path to human review.

Read the deep dive

Building Skill Libraries for Reliable Agent Work

Reliable agent work comes from packaging the parts humans usually repeat: procedures, scripts, templates, edge cases, and objective checks that an agent can discover and run at the right moment.

Read the deep dive

Using Sub-Agents Without Creating Chaos

Sub-agents work when they are isolated, narrowly scoped, and forced through independent review before their outputs are merged into the main line of work.

Read the deep dive

Verification Layers for Agents That Touch Real Systems

Agents become usable around real systems when every action is wrapped in layered verification: scoped specs, automated checks, observable execution, model critique, human approval, and hard tool limits.

Read the deep dive

Choosing Models and Harnesses for Agent Workloads

Agent systems work best when model choice is treated as routing infrastructure: match each workload to the right mix of frontier APIs, open weights, local inference, desktop harnesses, and managed long-running environments.

Read the deep dive

Agent Memory and Business Context That Stays Useful

Useful agent memory is not a bigger prompt, but a routing system that separates durable business context from noisy app data and gives agents a narrow path to the right source.
